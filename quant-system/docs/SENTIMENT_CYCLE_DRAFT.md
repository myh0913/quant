## 2. 六态状态机

```
冰点 → 冰点转折 → 修复 → 加速/高潮 → 分歧 → 退潮
  ↑_____________________________________________|
```

| 状态 | 进入条件（满足其一即进入） | 2026-09-04 对照 |
|---|---|---|
| **退潮** 🔴 | 炸板率≥35% 或 跌停≥50 或 龙头跌停 或 温度<25 | ✅ 炸板率55% → **退潮** |
| **分歧** 🟠 | 炸板率25-35% 或 昨日涨停溢价<0 或 晋级率<15% | （被退潮覆盖） |
| **加速/高潮** 🟢 | 温度≥60 且 晋级率≥25% 且 连板高度≥5 | ❌ |
| **修复** 🟡 | 温度30-60 且 涨停≥40 且 炸板率<25% | ❌（炸板率55%） |
| **冰点转折** 🔵 | 前日冰点 + 今日(涨停≥50 或 温度回升≥40 或 出现新空间板) | ❌ |
| **冰点** ⚪ | 温度<30 且 (跌停≥30 或 涨停<30) | ❌ |

**判定优先级（安全优先）**：退潮 > 分歧 > 冰点 > 加速 > 修复 > 冰点转折。多条件同时满足取更保守状态。

## 3. 与三策略联动

| 状态 | 策略一 竞价抢筹 | 策略二 连板捉妖 | 策略三 龙回头 | 仓位系数 |
|---|---|---|---|---|
| 冰点 | ❌ | ❌ | ❌ | 0（只观察转折信号） |
| 冰点转折 | ✅ 试仓 | ❌ | ❌ | 0.3x |
| 修复 | ✅ | ✅ 低仓位 | ✅ | 0.5x |
| 加速/高潮 | ✅ | ✅ | ✅ | 1.0x |
| 分歧 | ⚠️ 降级 | ❌ | ✅（策略三本来适合分歧） | 0.5x |
| 退潮 | ❌ | ❌ | ❌ | 0（禁止接力） |

**覆盖否决（任何状态下触发即至少降一级，退潮类直接归退潮）**：
- 龙头 ∈ 东财重点监控/严重异常 → 用户规则"龙头严重监管要卖出"
- 黑天鹅近似：单日大盘跌>3% 或 跌停>100 → 直接退潮处理

**情绪过于一致（用户卖出条件）近似**：温度≥75 且 连板高度≥6 → 标记"过热"，仓位减半（不直接禁买，因为高潮期也可能延续）

## 4. 状态转移规则

- **收紧立即**：进入退潮/分歧只需当日满足（安全优先，不等确认）
- **放宽需确认**：进入修复/加速需连续 2 个交易日满足（防单日反弹诱多）
- 冰点转折特殊：冰点后首日出现信号即可标记（转折本身就是"第一天看出来"）
